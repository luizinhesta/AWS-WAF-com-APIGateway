Sobre o Projeto

Este laboratório demonstra como o AWS WAF pode identificar e bloquear padrões relacionados a Cross-Site Scripting (XSS) antes que a requisição alcance a aplicação.

Existem dois endpoints neste laboratório:

🔓

SEM WAF

Requisições passam direto para o CloudFront/origem, sem inspeção de WAF.

🛡

COM WAF

Requisições são inspecionadas pelo AWS WAF antes de chegar ao S3.

Ambos os endpoints mostram exatamente o mesmo conteúdo armazenado no S3. A única diferença é a presença da Web ACL do AWS WAF.

O que é XSS

Cross-Site Scripting (XSS) é uma vulnerabilidade na qual conteúdo contendo scripts maliciosos pode ser enviado para uma aplicação web.

Importante: Neste laboratório nenhum script será efetivamente executado no servidor.

O objetivo é apenas enviar uma string com padrão característico de XSS para verificar se o AWS WAF identifica e bloqueia a requisição.

Exemplo de padrão típico de XSS enviado via query string:

?search=<script>alert(1)</script>
